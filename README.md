# Daruma Twitch Chat Customizer

Twitch (`www.twitch.tv`) とクリエイターダッシュボード (`dashboard.twitch.tv`) の両方に対応した、チャット欄・スタンプ・チャネポを快適にする Chrome 拡張機能です（Chromium 系ブラウザの Edge / Brave などでも動作します）。

## 導入手順（Chrome / Edge / Brave 等）

1. 配布された ZIP ファイル（`twitch-chat-customizer-v*.zip`）をすべて展開（解凍）します。
   - 中に `twitch-chat-customizer` フォルダ（`manifest.json` が入っているフォルダ）ができていることを確認してください。
   - ※ あとからフォルダを移動・削除すると拡張機能が無効になるため、ドキュメントフォルダなど消さない場所に置いてください。
2. ブラウザで `chrome://extensions/`（Edge は `edge://extensions/`）を開きます。
3. 右上（または左メニュー）の **デベロッパーモード** をオンにします。
4. **パッケージ化されていない拡張機能を読み込む** をクリックし、展開した `twitch-chat-customizer` フォルダを選択します。
5. すでに開いている Twitch のタブがある場合は、タブを再読み込み（`F5`）すると有効になります。

## アップデート方法

1. 新しいバージョンの ZIP を展開し、既存の `twitch-chat-customizer` フォルダへ上書きします。
2. `chrome://extensions/` を開き、「Twitch Chat Customizer」カードの **再読み込み（↻）** アイコンをクリックします。
3. 設定・お気に入りスタンプ・配信者の並び順はそのまま引き継がれます。

## 主な機能

ブラウザ右上の拡張機能アイコンから、機能ごとの ON/OFF や細かい調整ができます。

1. **コメント欄の横幅調整（視聴画面）**
   - チャット欄の横幅を `px`（`240px〜800px`、初期値 `340px`）またはウィンドウ比率 `%`（`12%〜50%`、初期値 `22%`）で指定でき、コメント欄左端のドラッグハンドルでもサイズ調整できます（ダブルクリックで初期値にリセット）。

2. **共有スタンプピッカー（視聴画面・ダッシュボード共通）**
   - **お気に入り＆配信者並び替え**: スタンプを右クリックでお気に入りに登録・解除でき、長押しドラッグでお気に入りや配信者アイコンの並び順を入れ替えられます。
   - **フォロワースタンプ**: 対象チャンネル内でのみ表示・入力できます。お気に入りには登録できません。
   - **現在チャンネルを先頭に固定**: いま見ているチャンネルのスタンプをお気に入り直下に自動表示します。
   - **サイズ調整（スライダー＆ドラッグ）**: ピッカーの端や角をドラッグして横幅・縦幅を直感的に変更でき（ダブルクリックで初期サイズにリセット）、横幅は `px` / `%` を切り替えられます。ポップアップのスライダー操作中はピッカーが自動で開いてリアルタイムに反映されます。
   - **スタンプ選択後も開いたまま**: 連続入力しやすい動作（設定で従来の自動クローズにも変更可能）と、右端のアイコンまたは `Shift+クリック` による Twitch 標準ピッカー呼び出し、チャネポピッカーとの排他表示に対応しています。
   - **スタンプ管理ページ**: ポップアップの「管理 ↗」ボタンから大きな画面で検索・整理・お気に入り追加ができます（`Ctrl+Z` でやり直し対応）。

3. **チャネポピッカー**
   - **コンパクト一覧表示・初期タブ改善**: チャンネルポイント報酬を見やすい1列リストで表示し（「すべて」タブを省いてチャネポを初期表示、開閉アニメーションを抑制）、文字サイズ（小・中・大）を選べます。
   - **サイズ調整（スライダー＆ドラッグ）**: ピッカーの端や角をドラッグして横幅・縦幅を調整でき（ダブルクリックで初期サイズにリセット）、横幅は `px` / `%` を切り替えられます。ポップアップのスライダー操作中はピッカーが自動で開いてリアルタイムに反映されます。
   - **ワンクリック交換**: 右側のポイントボタンを押すと確認画面を挟まず即座に交換できます（文字入力などが必要な報酬は通常画面が開きます）。
   - **交換可否の事前チェック**: 開いたときに交換できない報酬を自動でグレー表示します。
   - **交換成功後の自動クローズ**: 交換完了後に自動で閉じるかどうかを設定できます。

4. **バックアップ・メンテナンス**
   - 設定・お気に入り・並び順を JSON ファイルとして書き出し／読み込みできます。
   - 設定の初期化（2段階リセット）やスタンプキャッシュの消去もポップアップから行えます。

## プライバシーについて

外部サーバーへの設定・閲覧履歴などの送信は一切行いません。設定やお気に入りスタンプのデータはすべてお使いのブラウザのローカルストレージ内にのみ保存されます。


## 開発・ビルド

Node.js と Windows PowerShell が必要です。外部 npm パッケージのインストールは不要です。

```powershell
npm test
npm run dist
```

`dist/` に読み込み用フォルダーと配布 ZIP が生成されます。ビルド時に開発用の自動再読み込み処理を除去します。
個人用の設定・お気に入り・スタンプキャッシュはブラウザー内に保存され、リポジトリには含まれません。

Twitch の画面や内部データ形式の変更により、動作しなくなる場合があります。Twitch 公式の拡張機能ではありません。
